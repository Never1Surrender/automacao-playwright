GUIA PRÁTICO DE AUTOMAÇÃO DE QA

Resumo de Conceitos, Comandos de Terminal, Estratégia e Playwright

1. Conceitos de Engenharia de Qualidade

A Pirâmide de Testes

  • Topo (E2E / Interface): Mais lentos e caros. Simulam a jornada real do usuário no navegador (ex: Playwright, Cypress).
  • Meio (Serviços / APIs): Rápidos e estáveis. Testam integração e regras de negócio sem interface gráfica.
  • Base (Unidade): Ultrarrápidos e em grande quantidade. Focados em funções isoladas de código (feitos pelos desenvolvedores).

Caminhos Críticos (Critical Path)

Pergunta de ouro: "Se essa funcionalidade quebrar em produção agora, a empresa para de faturar ou o usuário fica impedido de acessar o produto?"
  • Prioridade Máxima E2E: Checkout/Compra, Pagamento, Login e Criação de Conta.
  • Evitar no E2E: Textos estáticos de rodapé e validações exaustivas de formulário (devem ser validadas em testes unitários).

CI/CD e Pipelines

  • Pipeline: Esteira automatizada de execução na nuvem.
  • CI (Continuous Integration): Roda os testes de QA automaticamente a cada código novo enviado pelos desenvolvedores, funcionando como trava de segurança.
  • CD (Continuous Delivery): Publica a versão em produção automaticamente assim que todos os testes da esteira passam com sucesso (🟢).

2. Comandos Essenciais do Terminal (Linux)

Ação Comando
Criar e entrar na pasta mkdir meu-projeto && cd meu-projeto
Instalar Playwright npm init playwright@latest
Gravar ações na tela (Codegen) npx playwright codegen https://site.com
Executar em Modo Visual (UI Mode) npx playwright test --ui
Rodar com navegador visível npx playwright test login.spec.js --headed
Rodar em câmera lenta (1s) npx playwright test --headed --slow-mo=1000

3. Seletores e Acessibilidade (Locators)

A. Papéis de Acessibilidade (Playwright)

// Botão
await page.getByRole('button', { name: 'Login' }).click();

// Link de navegação
await page.getByRole('link', { name: 'Signup / Login' }).click();

// Campo de texto / Input
await page.getByRole('textbox', { name: 'Email Address' }).fill('thais@teste.com');

// Radio Button (Marcar bolinha)
await page.getByRole('radio', { name: 'Mrs.' }).check();

// Select / Lista Suspensa
await page.getByLabel('Country *').selectOption('United States');

B. Hierarquia Universal de Seletores (HTML / DevTools)

Prioridade Tipo Sintaxe
1º (Ideal) Atributo de Teste [data-qa="login-email"] ou [data-testid="..."]
2º ID Único #id-do-elemento
3º Atributo Name [name="email"]
4º XPath por Texto //button[text()='Login']
5º (Evitar) Classe CSS .btn-submit-v2 (Frágil a mudanças de layout)

4. Scripts Prontos de Referência

Login com Validação de Erro

import { test, expect } from '@playwright/test';

test('Tentativa de login com credenciais incorretas', async ({ page }) => {
  // 1. Arrange & Act
  await page.goto('https://automationexercise.com');
  await page.getByRole('link', { name: 'Signup / Login' }).click();

  // 2. Preenchimento
  await page.locator('form').filter({ hasText: 'Login' }).getByPlaceholder('Email Address').fill('invalido@teste.com');
  await page.getByRole('textbox', { name: 'Password' }).fill('senhaIncorreta123');
  await page.getByRole('button', { name: 'Login' }).click();

  // 3. Assert (Validação)
  const mensagemErro = page.locator('p', { hasText: 'Your email or password is incorrect!' });
  await expect(mensagemErro).toBeVisible();
});

Cadastro com E-mail Dinâmico (Timestamp)

import { test, expect } from '@playwright/test';

test('Cadastro de novo usuário', async ({ page }) => {
  // Evita erro de email duplicado
  const emailUnico = `thais_${Date.now()}@teste.com`;

  await page.goto('https://automationexercise.com/');
  await page.getByRole('link', { name: 'Signup / Login' }).click();

  await page.getByRole('textbox', { name: 'Name' }).fill('Thais');
  await page.locator('form').filter({ hasText: 'Signup' }).getByPlaceholder('Email Address').fill(emailUnico);
  await page.getByRole('button', { name: 'Signup' }).click();

  // Formulário de Conta
  await page.getByRole('radio', { name: 'Mrs.' }).check();
  await page.getByRole('textbox', { name: 'Password *' }).fill('@Diario123!');
  await page.locator('#days').selectOption('5');
  await page.locator('#months').selectOption('5');
  await page.locator('#years').selectOption('2000');

  // Endereço
  await page.getByRole('textbox', { name: 'First name *' }).fill('Thais');
  await page.getByRole('textbox', { name: 'Last name *' }).fill('Araujo');
  await page.getByRole('textbox', { name: 'Address * (Street address, P.' }).fill('Rua dos Testes, 123');
  await page.getByLabel('Country *').selectOption('United States');
  await page.getByRole('textbox', { name: 'State *' }).fill('California');
  await page.getByRole('textbox', { name: 'City * Zipcode *' }).fill('Los Angeles');
  await page.locator('#zipcode').fill('90001');
  await page.getByRole('textbox', { name: 'Mobile Number *' }).fill('11999998888');

  await page.getByRole('button', { name: 'Create Account' }).click();

  // Validação
  await expect(page.getByText('Account Created!')).toBeVisible();
});
